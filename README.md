# 🎄 ASCII Art Christmas Interactive Experience

Una aplicación web interactiva de Navidad renderizada al 100% en **ASCII Art** utilizando Vanilla JavaScript con ES6 Modules y un motor de buffer de caracteres optimizado en HTML5 Canvas a 60 FPS con soporte de color, brillo CRT y proyección 3D con Z-Buffer.

## 🌟 Características
- **100% ASCII Art**: Gráficos de alta fidelidad dibujados carácter por carácter.
- **Árbol de Navidad 3D Matemático**: Cono volumétrico con rotación suave en el eje Y, estrella superior con rayos radiantes, adornos rojos, guirnaldas doradas y suelo reflectante con perspectiva.
- **Banner ASCII Personalizado**: `"Mauri te desea feliz navidad!!!"` sobre el árbol.
- **Sistema de Nieve ASCII Permanente**: Múltiples planos de profundidad, caracteres variados y deriva sinusoidal de viento.
- **TimeGateController (Singleton)**: Control de estado automático (`LOCKED` en cuenta regresiva vs `UNLOCKED` en Navidad).
- **Estética CRT Terminal**: Monitor retro con fondo negro `#05050a`, líneas de escaneo y brillo *text-shadow glow*.
- **Arquitectura SOLID & Clean Code**: Separación estricta de responsabilidades, interfaces segregadas e inyección de dependencias.
- **Desarrollado bajo Git Flow Estricto**: Commits semánticos basados en Conventional Commits.
